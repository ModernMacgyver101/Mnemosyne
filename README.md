Project Mnemosyne (OnTrack)

Mnemosyne is a secure, multi-functional productivity application designed for users who prioritize privacy and automated communication. At its core, it serves as a robust platform for reminders, task tracking, and note-taking, but it includes specialized features to keep your data hidden and ensure critical messages are sent on time.

🚀 Core Features

Task & Note Management: Basic, intuitive tools for jotting down notes, organizing task lists, and setting personal reminders.

Stealth Mode (Calculator Disguise): Privacy is paramount. The app can be disguised as a fully functional calculator, hiding your personal notes and tasks from prying eyes. Only you know the sequence to unlock the true application interface.

Automated SMS Reminders: Configure specific reminders to automatically send text messages to designated phone numbers at the exact time you set. Perfect for automated check-ins, critical alerts, or coordinated task management.

🛡️ Privacy First

Mnemosyne is built with the understanding that not all notes are meant to be seen by anyone who glances at your phone. The calculator disguise ensures your secure vault remains completely covert.

Note: This project is currently in development.
